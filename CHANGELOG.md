# changelog

## 1.0.0

Initial public release.

- rich-text articles, wiki links, search, revisions, import, and export
- folio and wiki skins, keyboard navigation, and per-user appearance settings
- typed collections with table, board, list, and calendar views and starter kits
- film and series library mode with discovery, episode tracking, mood picks, and backup restore
- local authentication, optional oauth, role-based access, personal access tokens, and audit logs
- public api v1, generated api reference, and configurable modules
- self-hosting with postgresql and prisma migrations, docker, and vercel support
