# api v1

Arkivel exposes these public read endpoints:

- `GET /api/v1/articles`
- `GET /api/v1/categories`
- `GET /api/v1/tags`
- `GET /api/v1/search`

The machine-readable contract is at `/api/v1/contract`; OpenAPI is at `/api/v1/openapi.json`; the rendered reference is at `/api-docs`.

Use the response shapes in the generated contract. The API version is independent of the application release version.
